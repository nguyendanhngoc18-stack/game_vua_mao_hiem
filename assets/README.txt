Game files
==========

The original game file is kept at:

  assets/supper-tramper.swf

The Vietnamese version is:

  assets/supper-tramper-vi.swf

The page loads the Vietnamese version by default. It translates SWF text
fields; Chinese lettering baked into logos and artwork remains untranslated.

The page loads Ruffle 0.7.1 from the unpkg CDN. An internet connection is
required to load the player and its runtime files. To play offline, include
the complete matching Ruffle package locally and update index.html.
